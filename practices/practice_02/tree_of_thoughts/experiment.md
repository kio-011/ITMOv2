# Tree of Thoughts

- Решение, для которого нужны альтернативы:

## Выбор

- Выбранная комбинация: 
  - Инструмент: k6 + constant/ramping-arrival-rate.
  - Профиль: steady для base/soak/degradation; ramping для stress; явный прогрев и окна.
  - Модель данных: small/medium/large фиксированные доли; oversize — отдельный сценарий.
  - Наблюдаемость: k6 summary JSON + скриншоты percentiles/error; теги `endpoint/diff_size/scenario`.
  - Pass/Fail: численные пороги из задания ToT, бинарные условия; «допущение»/«подтверждено» помечены.
  - Инъекции: локальный прокси/мок LLM (10–12 с для 5–10%).
  - Реплицируемость: версии/BASE_URL/фикстуры/MIX/окна/summary и meta.json.

- Почему: максимальная сумма баллов по критериям; минимальные усилия на интеграцию при достаточной подтверждаемости результатов и бинарности Pass/Fail.
- Как проверим: запустить k6 с фикстурами diff, получить summary JSON и скриншоты; сверить Pass/Fail с таблицей; повторить прогоны с теми же параметрами и получить близкие результаты.
