Пример запуска (псевдокод, k6):

```bash
# base mix
BASE_URL=http://localhost:8000 \
SEED=42 \
DIFF_FILE_SMALL=fixtures/diff_small.txt \
DIFF_FILE_MEDIUM=fixtures/diff_medium.txt \
DIFF_FILE_LARGE=fixtures/diff_large.txt \
k6 run --vus 20 --duration 20m \
  --summary-export results/base_summary.json \
  -e BASE_URL=$BASE_URL -e SEED=$SEED \
  -e DIFF_FILE_SMALL=$DIFF_FILE_SMALL -e DIFF_FILE_MEDIUM=$DIFF_FILE_MEDIUM -e DIFF_FILE_LARGE=$DIFF_FILE_LARGE \
  -e MIX="70:25:5" \
  scripts/reviews_constant_arrival.js

# 413
BASE_URL=http://localhost:8000 \
DIFF_FILE_OVERSIZE=fixtures/diff_oversize.txt \
k6 run --vus 10 --duration 10m \
  --summary-export results/413_summary.json \
  -e BASE_URL=$BASE_URL -e DIFF_FILE_OVERSIZE=$DIFF_FILE_OVERSIZE \
  scripts/reviews_413.js
```

## Pass/Fail Gate

Общие правила: LLM timeout 10 с [подтверждено: CASE.md, REL-1]; 413 для >20 000 [подтверждено: CASE.md, API-1].

| Сценарий | Нагрузка | Пороги Pass | Условия FAIL | Статус |
|---|---|---|---|---|
| Base mix | 10 rps, 20 мин (2 мин прогрев) | p95 ≤ 8 с; p99 ≤ 10 с; http_req_failed ≤ 1% | Любой порог нарушен | допущение; 10 с опирается на REL-1 |
| Large (<413) | 3 rps, 15 мин | p95 ≤ 9 с; p99 ≤ 10 с; http_req_failed ≤ 1% | Любой порог нарушен | допущение |
| Oversize 413 | 5 rps, 10 мин | 100% 413; p95 ≤ 200 мс; 0 вызовов LLM | Не 413; p95 > 200 мс; дергается LLM | 413 — подтверждено; остальное — допущение |
| LLM degradation | 5 rps, 15 мин; задержка 8 с | p99 ≤ 10 с; ошибки ≤ 1%; схема OUT-1 | p99 > 10 с или ошибки > 1% | 10 с — подтверждено REL-1; остальное — допущение |
| Soak | 5 rps, 1 ч | Дрейф p95 ≤ +10%; ошибки ≤ 1% | Превышение дрифта или ошибок | допущение |
| Stress ramp | 2→20 rps, +2/5 мин | До 12 rps: p95 ≤ 8 с; ошибки ≤ 1%; далее — без взрывного 5xx | Нарушение до 12 rps или 5xx > 2% | допущение |
