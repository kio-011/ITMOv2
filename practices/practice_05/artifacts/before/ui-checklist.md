## Проверка по конституции проекта (v1.0.0)

- [x] I. Поведение, не реализация — нет имён классов, файлов, библиотек, компонентов,
      эндпоинтов и полей API. Упоминания CSV, размеров в МБ и ширины экрана — это
      пользовательские ограничения продукта, а не выбор технологии.
- [x] II. Проверяемость — оценочные слова не используются; все пределы заданы числами
      (5 МБ, 10 000 строк, 3 с, 30 с, 30 мин, 1–255, 1–3650, 2000-01-01…2100-12-31,
      4.5:1, 44×44, 640 px, 200 %, 50 строк).
- [x] III. Границы и ошибки в требованиях — раздел 6 перечисляет состояния для каждого
      экрана, включая пустой, слишком большой, частично некорректный и полностью
      некорректный вход; ошибки — в требованиях и в таблице текстов, не в примечаниях.
- [x] IV. Деньги — все суммы записаны строками с двумя знаками (`"15.49"`, `"17.99"`,
      `"0.00"`, `"135.86"`); плавающая точка не упоминается.
- [x] V. Только свои данные — соглашения документа и SRV-015 фиксируют принадлежность;
      данные другого пользователя не появляются ни в одном состоянии.
- [x] VI. Два языка — раздел 8 даёт ru и en для каждого ключа (заголовки, подписи,
      кнопки, пустые состояния, ошибки, итог); AC-020 это проверяет.
- [x] VII. Ничего без подтверждения — SC-004, FR-003, FR-014, AC-017, AC-018.
- [x] VIII. Допущения помечены — раздел 11 (16 требований к серверу) и раздел 12
      (14 допущений с последствиями) разделены; имена полей не придуманы.
- [x] IX. Модель и API не меняются — ASM-009 фиксирует отказ от нового признака
      «создана импортом», ASM-010 — отказ от нового действия отмены; раздел 14 п. 12.
- [x] X. Вне рамок — раздел 14 включает банковские API, OCR, PDF, почту, очереди,
      уведомления, Pro.
