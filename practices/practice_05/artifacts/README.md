# Сдаточные артефакты

Складывать сюда по ходу работы. Пусто на старте — заполняется по шагам из `../README.md`.

```
before/ui-spec.md          спека UI, снимок после шага 4, до согласования
before/logic-spec.md       спека логики, снимок после шага 4
contract.md                общий контракт, шаг 6
after/ui-spec.md           спека UI после шага 7
after/logic-spec.md        спека логики после шага 7
analyze-output.md          вывод /speckit-analyze, шаг 9а
checks.txt                 вывод pytest, ruff, npm test, npm run build
framework-comparison.md    шаг 10
reflection.md              шаг 11
demo.md                    ссылка на запись + сценарий
```

**Снимки `before/` снимаются до первой правки по контракту.** Восстановить их потом
нельзя, а это половина второго критерия: «UI и логика, согласованные до кода» —
проверяющий должен увидеть, что до согласования спеки действительно расходились.

Ещё полезно, хоть и не обязательно: сохранить `diff before/ui-spec.md after/ui-spec.md`
и то же для логики — наглядно показывает цену согласования.
