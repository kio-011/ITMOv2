их сдали, до единой правки.

## Как запускать чаты команд

Два **разных** окна Claude Code, в каждом рабочая директория — папка своей команды:

```bash
cd practices/practice_05/team-ui     # окно 1
cd practices/practice_05/team-logic  # окно 2
```

Правила на шаги 1–4:
1. Контекст между окнами не переносится, `/compact` и пересказ чужих решений запрещены.
2. Ни один чат не читает папку другого. Запрет вписан в пре-промпт, но это инструкция,
   а не песочница — проверяй по логу инструментов, что чтений наружу не было.
3. Вопрос агента, относящийся к чужой зоне, человек **не разрешает**: агент должен
   решить сам и записать в раздел допущений. Если ответить обоим одинаково, команды
   сойдутся и согласовывать будет нечего.
