# Что зашито в `statement-sample.csv`

Файл — эталон входных данных. Обе команды видят его, но выводы делают сами.
38 строк, июль–октябрь 2026, валюта USD (совпадает с демо-данными `./scripts/dev.sh --seed`).

| Что в файле | Строк | Зачем |
|---|---|---|
| `NETFLIX.COM AMSTERDAM` | 4 | подписка **и** подорожание: 15.49 три раза, затем 17.99 — это та же подписка или новая? |
| `SPOTIFY P0A1B2C3` | 4 | у демо-пользователя Spotify **уже заведён** — случай дедупликации |
| `ADOBE CREATIVE CLOUD` | 4 | чистая ежемесячная подписка, которой нет в профиле |
| `CLAUDE.AI SUBSCRIPTION` | 4 | то же, круглая сумма |
| `NOTION LABS INC` | 4 | то же |
| `ЯНДЕКС ПЛЮС ПОДПИСКА` | 4 | кириллица в названии мерчанта |
| `VPN SERVICE LTD` | 2 | интервал ~90 дней, всего два повтора — граница «сколько повторов достаточно» |
| `GITHUB INC PRO ANNUAL` | 1 | годовая подписка, в выписке за 4 месяца встречается один раз — **не должна** попасть в кандидаты, хотя по названию похожа |
| `PYATEROCHKA 4412` | 2 | один мерчант, разные суммы (23.41 и 31.08) — не подписка |
| `AMZN MKTP US*...` | 2 | разные суффиксы в описании и разные суммы — не подписка, проверка нормализации |
| `SALARY ACME CORP` | 4 | регулярный **приход**, идеально периодичный — ловушка для наивного алгоритма |
| `TRANSFER TO IVAN P.`, `UBER TRIP` | 2 | разовые операции |
| `BROKEN ROW NO AMOUNT` | 1 | пустая сумма — частичная ошибка разбора |
| строка с запятой внутри кавычек | 1 | `"AMZN MKTP US*2K4L5,MX"` — корректный CSV-парсер обязателен |

Расходы записаны отрицательными числами, приходы — положительными. Это факт формата,
а не решение команды: интерпретировать его каждая команда может по-своему.

## Ожидаемый результат (эталон приёмки)

Зафиксирован в контракте, раздел 8, и проверяется тестом
`backend/tests/test_statement_detection.py`:

**Основной список — 6 кандидатов:** Claude.ai (90), Adobe Creative Cloud (90),
Яндекс Плюс (90), Notion Labs (80), Spotify (80), Netflix (78, шаг цены
`15.49` → `17.99`, предлагается последняя сумма).

**Список «требует проверки» — 2:** VPN Service (`custom_days` 90, два списания,
40) и Github Pro Annual (`yearly` по слову `ANNUAL`, одно списание, 30).

**Отсеяно:** зарплата (приход), перевод, Uber (одно списание без маркера периода),
Пятёрочка и Amazon (нестабильная сумма).

**Пропущена** 1 строка из 38 (`row.amount_missing`), признак неполного разбора
выставлен, импорт при этом успешен.

> Прежняя редакция этого файла утверждала, что GitHub в кандидаты попасть не должен.
> Серверная команда решила иначе — показывать его во втором списке при явном
> текстовом маркере периода, — и контракт закрепил этот вариант.
