При пустом имени подписчика **поднимается исключение `ValueError` с сообщением "empty name"**.
**Подтверждение кодом:**
```python
# service.py, строка 5-6
if not name.strip():
    raise ValueError("empty name")
```
Функция проверяет, что имя после удаления пробелов (`strip()`) не пустое. Если оно пустое (или содержит только пробельные символы), выбрасывается исключение.
