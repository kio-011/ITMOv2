Summary: сервис AI-reviewer принимает diff PR, отправляет его внешнему LLM и возвращает совет по ревью. В текущем diff (TRAINING_PR.diff) добавлены метод `review()` и POST-ручка `/api/reviews`, но не реализованы обязательные правила SEC-1, API-1, REL-1, OUT-1, OBS-1. ## Context Pack для первого рабочего сценария

### Факты и правила

- SEC-1: перед отправкой во внешний LLM из diff удаляются токены, пароли и приватные ключи.
- API-1: diff длиннее 20 000 символов отклоняется с HTTP 413.
- REL-1: внешний LLM-вызов имеет timeout 10 секунд; ошибка превращается в контролируемый ответ.
- OUT-1: ответ содержит `summary`, массив `risks` и массив `checks`. В `risks` максимум три элемента с полями `file`, `line`, `evidence`, `risk`.
- SCOPE-1: сервис только советует; он не пишет код и не выполняет действия в GitHub.
- QA-1: риск включается в ответ, только если он подтверждён строкой diff или правилом репозитория.
- OBS-1: в лог пишутся только `request_id`, длительность и статус; diff и ответ модели не логируются.

### Формат входа и результата

- Вход: JSON с ключом `diff` (строка, ≤ 20000 символов).
- Результат: JSON с полями `summary: str`, `risks: list[{file, line, evidence, risk}]`, `checks: list[str]`.

### Ограничения и запрещённые действия

- Запрещено: approve, merge, edit (SCOPE-1). Не логировать содержимое diff/ответа (OBS-1).

### Хороший пример

- Принятие diff ≤ 20000; секреты удалены; вызов LLM с таймаутом 10с; контролируемая ошибка при таймауте; ответ со структурами `summary`, `risks`, `checks`.

### Плохой пример

- Ответ `{"comment": "..."}` без структур; передача сырых diff в LLM; отсутствие лимита длины; отсутствие таймаута/обработки ошибок.

### Что пока неизвестно

- Правила маскирования секретов (точные паттерны); идентификатор провайдера LLM; требования к локализации ответа.

## Как использовали AI

- Для чего: составление контекста и выявление несоответствий правилам на основе TRAINING_PR.diff.
- Тип промпта: zero-shot и master prompt.
- Строка в [`prompts.md`](prompts.md): записи P1-01 и блок Master Prompt v1.
- Что проверили и исправили сами: сопоставление diff строк и нарушений правил; валидация, что риски опираются на evidence из diff и формализованные правила.
