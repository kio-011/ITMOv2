# Анализ процесса: AS IS и TO BE

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

## AS IS

Поток от запроса до ответа сейчас следующий (по TRAINING_PR.diff):

- Клиент отправляет POST `/api/reviews` с телом `{ "diff": "..." }`.
- В `app/api.py` запрос сразу проксируется: `review_service.review(payload["diff"])` без валидации входа и обработки ошибок.
- В `app/review_service.py` формируется prompt и вызывается `llm.generate(prompt)` без таймаута/try-except.
- Ответ возвращается как `{"comment": answer}` — не соответствует требуемому формату OUT-1.

Затыки и риски:
- Нет лимита на длину diff (API-1), дифф >20000 не отклоняется.
- Нет маскирования секретов перед вызовом внешнего LLM (SEC-1).
- Нет таймаута и контролируемой обработки ошибок внешнего вызова (REL-1) — возможны 5xx/подвисания.
- Формат ответа не структурирован (OUT-1), автоматическая обработка невозможна.
- Нет минимального логирования только метаданных (OBS-1).

## TO BE

```mermaid
flowchart TD
    A[Клиент POST /api/reviews\n{diff}] --> B{API-1: длина ≤ 20000?}
    B -- нет --> E[HTTP 413 Request Entity Too Large]
    B -- да --> C[SEC-1: маскировать секреты в diff]
    C --> D[REL-1: вызвать LLM с таймаутом 10с]
    D -->|таймаут/ошибка| F[Контролируемый ответ без 5xx]
    D -->|успех| G[OUT-1: собрать summary, risks(≤3), checks]
    F --> H[OBS-1: логировать только request_id, длительность, статус]
    G --> H
    H --> I[HTTP 200 JSON OUT-1]
```

## Разница

| Что меняется | AS IS | TO BE | Как проверим изменение |
|---|---|---|---|
| Формат результата (OUT-1) | `{"comment": "..."}` | `{summary, risks[≤3{file,line,evidence,risk}], checks[]}` | Интеграционный вызов `/api/reviews` с коротким diff → 200 и наличие ключей `summary`, `risks`, `checks`; валидация типов и лимита длины `risks`. |
| Таймаут и ошибки LLM (REL-1) | Нет таймаута/обработки; возможны 5xx/подвисание | Таймаут 10с; при ошибке — контролируемый структурный ответ без 5xx | Подменить LLM на заглушку с задержкой >10с → статус не 5xx, тело в формате OUT-1 с `summary` о таймауте, `risks=[]`. |
| Лимит длины (API-1) | Нет проверки; большие диффы уходят во внешний LLM | Проверка длины на входе; >20000 → HTTP 413 | Отправить diff длиной 20001 → 413; граничное 20000 → 200. |
